# Aryan Trading Classes: website

Marketing website for an offline stock market training academy. Goal: get visitors to
**book a free demo class**, **download the syllabus** or **ask about batches on WhatsApp**.

- **Stack:** Next.js (App Router, static export) + TypeScript + Tailwind CSS v4
- **Forms:** Web3Forms or Formspree (no own server)
- **Hosting:** Cloudflare Pages (static files in `out/`)
- **Checked:** `npm run build` and `npm run lint` pass on Next.js 16.4.6, Node 22

Guides in this repo: **DEPLOYMENT.md** (go live) and **HANDOVER.md** (transfer to client and maintenance).

## Quick start (VS Code)

```bash
npm install
cp .env.example .env.local     # then edit the values
npm run dev                     # http://localhost:3000
```

Other commands:

| Command | What it does |
| --- | --- |
| `npm run build` | Creates the final static site in `out/` |
| `npm run lint` | Checks code quality |
| `npm run typecheck` | Checks TypeScript types |
| `npm run check:launch` | Fails while sample values or `[CONFIRM]` placeholders remain |

To preview the built site: `npm run build` then `npx serve out`.

## Folder structure

```
app/                  Pages and site-wide files
  layout.tsx          Fonts, SEO meta tags, Open Graph, structured data
  page.tsx            Home page (assembles the sections)
  privacy/ terms/ risk-disclosure/   Legal pages (DRAFTS)
  sitemap.ts robots.ts not-found.tsx icon.svg globals.css
  fonts/              Self-hosted fonts (open licence files included)
components/           One file per section: Hero, Courses, Faq, DemoForm, ...
lib/site.ts           Business facts + env settings (phone, WhatsApp, form, address)
lib/content.ts        All website copy: courses, FAQs, steps
public/               og.png, syllabus PDF, _headers (Cloudflare security headers)
scripts/check-launch.mjs   Pre-launch safety check
.env.example          Names of all settings (copy to .env.local)
```

## What to edit

| To change | Edit |
| --- | --- |
| Phone, WhatsApp, email, site address, form key | `.env.local` (and Cloudflare variables when live) |
| Classroom address, opening hours, business name | `lib/site.ts` |
| Courses, FAQs, audience text, steps | `lib/content.ts` |
| Colours | `app/globals.css` (the `@theme` block) |
| Syllabus | Replace `public/aryan-trading-syllabus.pdf` (keep the file name) |
| Share image | Replace `public/og.png` with a 1200x630 image |
| Legal text | `app/privacy`, `app/terms`, `app/risk-disclosure` |

## Content to confirm with the client (before launch)

All copy is draft text written from the brief. The client must approve it. Items that
**must** come from the client are marked `[CONFIRM]` in the code, and `npm run check:launch` will not pass until they are replaced.

- [ ] Registered business name, classroom address, opening hours
- [ ] Phone, WhatsApp number, email
- [ ] Course names, levels and topic lists in `lib/content.ts`
- [ ] The statements that the classes are offline and that no tips, PMS or advisory are given (matches the original site's disclosure)
- [ ] Official syllabus PDF (the current file is a placeholder draft)
- [ ] Privacy, Terms (fees, refunds, court jurisdiction) and Risk pages, reviewed by a lawyer
- [ ] Brand colours and logo (the "AT" monogram and colours are a proposal)
- [ ] A real photo of the classroom or mentor (optional, recommended)

## Notes

- Every `NEXT_PUBLIC_*` value is written into the public website at build time. They are not secrets.
  Never add real secrets to this project. After changing a value on Cloudflare, redeploy.
- This version of Next.js is newer than many tutorials. `AGENTS.md` is generated by Next.js; keep it.
  Docs for this exact version are in `node_modules/next/dist/docs/`.
- No payments are included. This is an enquiry website.
